SYSTEM ANALYSIS REPORT: FINANCE TRACKER (MONEY TRACKER)
==========================================================

1. PROJECT OVERVIEW
-------------------
Money Tracker is a premium personal finance management application designed to help users track income, expenses, budgets, and loans. It provides a highly visual and interactive experience with real-time updates and smart analytics.

2. TECHNOLOGY STACK
-------------------
FRONTEND:
- Framework: React.js (v19)
- Styling: Tailwind CSS
- Animations: Framer Motion
- Icons: Lucide React
- Charts: Recharts
- Routing: React Router DOM (v7)
- State Management: React Context API (AuthContext, FinanceContext)
- Localization: i18next (Multi-language)
- PDF Generation: jsPDF & html2canvas

BACKEND:
- Runtime: Node.js
- Framework: Express.js
- Database: MongoDB with Mongoose ODM
- Authentication: JWT & Bcrypt.js
- Security: CORS, Dotenv

3. SYSTEM ARCHITECTURE
----------------------
FRONTEND:
- src/context: Centralized state for auth and finance data.
- src/pages: Views for Dashboard, Transactions, Budget, Loans, etc.
- src/components: Reusable UI (Sidebar, Navbar, Cards).
- src/utils: Helper functions (Formatting, PDF).

BACKEND:
- Models: Mongoose data schemas.
- Controllers: Business logic.
- Routes: API endpoints.
- Config: Database and environment setup.

4. KEY FEATURES & FUNCTIONALITY
-------------------------------
- Dashboard: Overview of balance, income, expenses, and loans with charts.
- Transaction Management: Tracking income/expenses with categories.
- Budgeting: Category-wise limits with progress and alerts.
- Loan Tracking: Managing borrowed/lent money and repayments.
- Professional Reporting: PDF reports (Monthly/Yearly) with detailed tables.
- Savings Goals: Tracking financial targets.
- Future Planning: Notes system for planned costs with notifications.
- Global Settings: Multi-currency and multi-language support.

5. DATA MODELS
--------------
- User: Name, Email, Password, Currency, 2FA, OTP.
- Transaction: Amount, Category, Type, Date, Description.
- Budget: Category, Limit, Month/Year.
- Loan: Person, Amount, Type, Due Date, Status.
- Note/Plan: Title, Content, Scheduled Date.
- Notification: Message, Type, Status.

6. SECURITY ANALYSIS
--------------------
- Authentication: Secure JWT-based sessions.
- Data Protection: Bcrypt password hashing.
- API Security: Protected routes ensuring data privacy.
- Verification: OTP email verification for auth flows.

7. RECOMMENDATIONS
------------------
- Automated Recurring Transactions (Subscriptions, Salary).
- Cloud Backup (Drive/Dropbox integration).
- Mobile PWA optimization.
- AI-based spending insights.
